# Shopify B2B / Wholesale System (Production Example)

This repository demonstrates a real-world B2B implementation in Shopify used for hybrid B2C + wholesale stores.

## Problem
Client needed:
- Separate pricing for wholesale customers
- Restricted product visibility
- Clean experience for both B2B & B2C users

## Solution
- Customer tagging system (wholesale / retail)
- Dynamic pricing logic
- Conditional product visibility
- Theme-level customization (no app dependency)

## Features
✔ Role-based pricing  
✔ Wholesale-only product visibility  
✔ Seamless B2C + B2B experience  
✔ Scalable architecture  

## Real Use Case
Used in stores similar to:
- Wholesale skincare brands
- Distributor-based ecommerce systems
